# The Dead Wall 2026 — site

Responsive, fast, and now with a light **Space Mahjong** cosmic theme. Whole site is about 5 MB
(down from ~90 MB). Every page shares one stylesheet.

## Editing content

- **Home page:** all text lives in the `EVENT = { … }` object near the bottom of `index.html`,
  under `★★★ EDIT EVERYTHING FOR 2026 HERE ★★★`.
- **Sub-pages** (`pages/…`): plain HTML — just edit the words between the tags. They all pull in
  `../style.css`, so they automatically match the home page.
- **Standings:** edit the `RESULTS` array at the bottom of `pages/standings.html`
  (`["Name", "+12.3"]`). It ranks and sorts itself. Currently showing the 2025 results.

## The Space Mahjong theme (what's new)

- **Starfield** behind every page (two SVG layers baked into `style.css` — no image requests;
  the fainter layer twinkles slowly).
- **Sparkle on hover** for the contest links, including the *Space Mahjong* link — they glow and
  throw little stars.
- **A rare comet** drifts across the hero every so often.
- A faint cosmic halo on section titles, and orbit-coloured **Dealer / Fortune / Curse** pills on
  the rules page.
- All motion respects `prefers-reduced-motion` — it goes calm/static for anyone who asks for that.

To dial any of it up or down, the whole cosmic block is clearly commented in `style.css`
(search for `SPACE MAHJONG`). The palette is the `:root` block at the very top.

## Registration form + public "wall of names"

The home page now has an **Enter the dungeon** section: a registration form on the left and a live
wall of registered names on the right (with a "N souls captured / X of 36 playing seats" counter).
Names are opt-in (a checkbox), emails are never shown, and playing vs non-playing show as different
tile colours.

**It needs a tiny free backend** — a static site can't store a shared list on its own. I've included
one in `backend/registration.gs` (Google Apps Script + a Google Sheet, ~5 min, no server, no cost):

1. Open `backend/registration.gs` and follow the SETUP comment at the top (create a Sheet ▸
   Extensions ▸ Apps Script ▸ paste ▸ Deploy as Web app ▸ copy the `/exec` URL).
2. Paste that URL into `EVENT.registration.endpoint` in `index.html`.

That's it — the form then writes sign-ups to your Sheet and the wall reads back from it (names read
via JSONP, sign-ups sent no-cors, so it works from GitHub Pages without any CORS setup).

**Until you add the endpoint it runs in demo mode** (saves to the visitor's own browser only, with a
visible amber "demo mode" note) so you can preview the whole flow. Configure the endpoint before you
launch, or the note stays and names won't be shared.

Other knobs in `EVENT.registration`: `seats` (the counter cap), `listedDefault` (is the wall
checkbox pre-ticked), `blurb`, and `closedNotice`. The section shows/hides with the same
`registrationOpen` flag as the hero button — set it to `false` and the form is replaced by the
closed notice while the wall still shows. **Moderation:** to remove a name, delete its row in the
Sheet.

## Past years (photo/video carousel)

The home page ends with a **Past years** section: a link to the previous site plus a swipeable
carousel of photos and clips. Clicking any item opens it full-screen (a lightbox with prev/next,
Esc to close). Everything is driven from `EVENT.pastYears` in `index.html`:

- Change the `url` / `linkLabel` / `blurb` to point at whatever "past" link you want.
- Add or remove items in the `media` array. Each entry is `{ type, src, alt }`; a `video` entry
  also needs a `poster`. Files live in `media/past/`.
- **Photos:** any web format (jpg/webp/png). The carousel shows them at a uniform height and the
  lightbox shows the full image, so portrait and landscape mix fine.
- **Videos:** must be H.264 `.mp4` (not HEVC/HEIC — phones often record those and they won't play
  in Chrome/Firefox). Use the same encode command as above, then add a poster with the poster line.

I converted your uploads for you: the HEIC → jpg, and the phone clip from HEVC → H.264 (it was
also rotated metadata-only, so I baked the rotation in). All six are already in `media/past/`.

## Encoding video (adverts / contest clips)

Always compress before uploading — raw clips and GIFs are huge:

    ffmpeg -i clip.mov -movflags +faststart -pix_fmt yuv420p \
      -vf "scale='min(800,iw)':-2" -c:v libx264 -crf 27 -preset slow -an media/NAME.mp4
    ffmpeg -i clip.mov -vframes 1 -q:v 5 media/NAME-poster.jpg
